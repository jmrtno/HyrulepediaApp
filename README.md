# 🧭 HyrulepediaApp

**Hyrulepedia** is an encyclopedia for *The Legend of Zelda: Breath of the Wild* and *Tears of the Kingdom*, built as an iOS app using Swift and SwiftUI.  
It provides detailed information on creatures, items, locations, drops, and more, sourced from a public (unofficial) API, all organized for easy browsing.

---

## 🚀 Features

- 📚 Complete in-game encyclopedia  
- 🔎 Fast and clean navigation  
- 🗺️ Detailed element information (descriptions, locations, and drops)  
- 📱 Native iOS UI for a smooth experience
